# Readers' Haven Public Library Website

Static informational website for the fictional Readers' Haven public library.
Built for **DevOps Fundamentals (SEST4663) - Assignment 02** (Docker multi-stage build).
Plain HTML and CSS only. Node.js and Parcel are used only as build tools.

## Project Structure

```
readers-haven-library/
|-- .gitignore
|-- .dockerignore
|-- Dockerfile
|-- package.json
|-- package-lock.json
|-- README.md
|-- src/
|   |-- index.html        (Home)
|   |-- collections.html  (Collections)
|   |-- membership.html   (Membership)
|   |-- services.html     (Digital Services)
|   `-- contact.html      (Contact & Feedback)
|-- styles/
|   `-- style.css         (shared stylesheet)
`-- dist/                 (generated by the build; never committed)
```

## Branching

| Branch | Purpose |
|---|---|
| `main` | Production-ready code (PRs need 3 approvals) |
| `develop` | Integration branch (PRs need 2 approvals) |
| `feature/<page-name>` | One per page, created from `develop` |
| `feature/dockerfile` | Team Lead's multi-stage Dockerfile |
| `release/v2.0` | Final testing branch |

## Build locally

```
npm ci
npm run build
```
The generated site is written to `dist/`.

## Build and run with Docker

```
docker image build -t <dockerhub-username>/readers-haven:v1-<page-name> .
docker container run -d --name haven-<dockerhub-username> -p 808<Sr>:80 <dockerhub-username>/readers-haven:v1-<page-name>
```
Open http://localhost:808<Sr> in a browser.
